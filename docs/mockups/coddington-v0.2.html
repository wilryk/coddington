8Trace status bar, top of screen

A slim status bar appears directly under the top bar, full width, the moment any trace starts — visible on every tab, not just Workspace. It never covers the tab bar or a control; it replaces the old bottom-corner "tracing…" chip everywhere that chip used to show up.

New: full-width status bar under the top bar — heliostats done / total, elapsed time, and Cancel. Visible while a trace runs on any tab; it never overlaps the tabs or the fidelity/run controls beneath it.

9Analysis — secondary irradiance & FEA exports

For layouts with a secondary (axicon shown), the timestep irradiance panel gains a Receiver / Secondary selector. The secondary map shows incident flux in the same colormap and units as the receiver map; beside it, a readout reports absorbed heat. A regular grid CSV — the FEA-oriented convention used everywhere a map exists — exports underneath.

New: the Receiver / Secondary selector only appears when the current layout has a secondary (axicon, Cassegrain) — prime-focus layouts never show it.
Absorbed = (1 − R) × incident, computed live; R (secondary reflectance) is now an explicit, visible field in Receiver & Tower rather than an assumed constant.
Export is the same regular x, y, flux grid convention used everywhere a map exists (§D) — comma-separated, units stated in commented header lines, targeting ANSYS External Data import.

10Heliostat Shape — error glossary, pointing error, measured error map

The optical-errors section gains a fourth input, pointing error, and hover tooltips form a small glossary — drawn open here on slope error to show the exact wording for sign-off. Below, a measured (FEA) error map can be imported and applies in Monte Carlo only; the sag map gains its own FEA export.

Sign-off item: the glossary wording shown open above (slope error) is the literal draft text from spec §G — specularity and pointing error get matching one-sentence tooltips.
The measured map applies on top of the analytic figure, in Monte Carlo only, and is pre-processed once at import into slope grids — per-ray lookup is a bilinear read, so trace cost is unaffected by map resolution.
Resolved 2026-08-25 (§K.1): pointing error is quoted as reflected-beam RMS — no factor-of-two on reflection is applied to the user's number. The label and tooltip state it explicitly; a vendor's mirror-normal spec must be doubled before entry.

11Fidelity picker with purpose subtitles

The run bar's three modes become cards, each with a one-line subtitle describing intent rather than algorithm. Monte Carlo's tooltip is drawn open here to show the honest trade-off wording; Ultra fast carries a footnote disclosing its estimated-occlusion sweep behavior (spec §B, in flight as a bug fix but visible here since it shares this UI).

Subtitles describe intent, not algorithm — a designer picks a mode by what they're trying to do, not by what the engine does internally. Full tooltip wording per mode is in spec §A.
Ultra fast's day-sweep header already discloses when shadowing/blocking was interpolated ("estimated occlusion between N anchors") so a published number is never silently approximate — see M9/M7's sweep panel.

12North field & vertical receiver research complete

A Field span control restricts the shipped radial-staggered generator to a sector (Full surround / Sector), and the flat receiver window generalizes to an oriented plane (Window facing: Down (surround) / Field, with a Tilt from vertical the designer sets — PS10 precedent ≈ 12.5°, never a fixed constant). Plan and elevation are drawn side by side here purely for this review; the app shows one at a time, exactly as in mockups 3–4.

Field span and Window facing both generalize the shipped radial-staggered generator and existing flat-window aiming/deposit — the published parameterization (Lipps & Vant-Hull 1978; Collado & Guallar 2012; SolarPILOT's angular field bound), not a new layout engine.
Resolved 2026-08-25 (§K.5): half-span defaults to ±60°, and receiver tilt defaults to Auto (optimal) — computed from the field, displayed, and overridable — since the literature ties the optimum to latitude and tower height (PS10 as-built ≈ 12.5°).
All positions (plan view, inspector) now display and edit in meters at 0.01 m; dimensions — window size, tower height — stay in mm. Acceptance test: a sector field with a flat, tilted window traced end to end — historically the exact combination that failed silently in SolarPILOT for flat receivers.

13Secondary perturbations

The Receiver & Tower stage's secondary controls (axicon shown) gain a Perturbations group: rigid-body decenter and tip/tilt about the vertex, a parametric warp for quick what-ifs, and a measured surface-deformation map — so alignment and figure error of the secondary can be studied, not just its design geometry. The 3D scene shows the perturbed secondary live, and a secondary sag map — the same idiom as the heliostat sag map — makes perturb → view sag → retrace → absorbed-heat one loop.

Rigid-body misalignment (decenter + tip/tilt) is exact geometry, not a statistical error term — it applies at every fidelity, and the 3D scene and corner rays show the perturbed secondary live, exactly like editing apex height or half angle.
The surface-deformation map behaves exactly like the heliostat measured map (M10/§E): Monte Carlo only, pre-processed once at import so trace cost is unaffected, same MC-only badge, same implied-RMS-slope report on the loaded chip.
Resolved 2026-08-25 (§K.6): parametric warp is in — defocus and astigmatism terms for quick what-ifs without an FEA file, summed with the imported map, Monte Carlo only.
The secondary sag map mirrors the heliostat sag map's visual idiom exactly (jet colormap, stated contour interval) and shows nominal + warp + imported map summed, with its own FEA export — so perturb → view sag → retrace → watch absorbed heat (§C) is one loop, not a round trip through a different screen.

Decisions these mockups encode

  • Fidelity in plain language — the picker states intent (§A), not algorithm; each mode's tooltip discloses its honest trade-off.
  • Ultra fast day sweeps interpolate shading/blocking between exact anchor timesteps (~1–2 % budget at low sun); single-instant traces stay exact (§B).
  • Secondary-mirror layouts (axicon, Cassegrain) get a Receiver/Secondary map selector and an absorbed-heat readout — absorbed = (1 − R) × incident, R a visible Receiver & Tower input (§C).
  • One CSV convention everywhere a map exists — sag, receiver, secondary — ANSYS External Data–oriented, units always stated in the header (§D).
  • Measured (FEA) sag-deviation maps import in Monte Carlo only, pre-processed once so trace cost is unchanged; the implied RMS slope is reported so it's never double-counted against the analytic figure (§E).
  • Pointing error joins slope error, specularity, and reflectance as a fourth optical input — quasi-static per instant in Monte Carlo, a broadening term in cone modes, default 0 mrad (§F).
  • Tooltips app-wide — the optical-error glossary wording (M10) is part of this sign-off (§G).
  • Positions in meters at 0.01 m everywhere they're shown or edited; dimensions stay in mm (§H).
  • Polar (sector) fields generalize the shipped radial-staggered generator with a Field span control; the receiver window gains an oriented-plane facing + tilt-from-vertical, PS10-precedented but user-set (§I).
  • Secondary-mirror perturbations — rigid-body decenter/tip/tilt trace at every fidelity as exact geometry, live in the 3D scene; a measured deformation map layers on top in Monte Carlo only, same convention as the heliostat map (§E2).
  • Parametric warp + secondary sag map (confirmed 2026-08-25) — defocus and astigmatism terms give quick what-ifs without an FEA file, summed with the imported map; a "View sag" for the secondary mirrors the heliostat sag map exactly, with its own FEA export, closing the perturb → view sag → retrace → absorbed-heat loop on one screen (§E2).

Open questions — all resolved 2026-08-25

  • Pointing-error convention → reflected-beam RMS; the label and tooltip say so (§F/§K.1).
  • Dimension units → confirmed: mirror/receiver dimensions and sag stay in mm; positions move to meters at 0.01 m (§H/§K.2).
  • Secondary reflectance default → 0.90, the value already in use, now a visible input (§C/§K.3).
  • Ultra-fast anchor spacing → auto-chosen to the error budget — dense near sunrise/sunset where occlusion changes fast, sparse at midday (§B/§K.4).
  • Polar-field defaults → half-span ±60°; receiver tilt defaults to Auto (optimal) with manual override (§I/§K.5).
  • Secondary parametric warp → in, with the secondary sag map and FEA export — see M13 (§E2/§K.6).
